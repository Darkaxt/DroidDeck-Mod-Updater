Revamped Updater becomes **DroidDeck Mod Updater**: one app for several modded games.

- New **Warhammer Survivors** tab: installs and updates [WHSurvivorsTweaks](https://github.com/Darkaxt/DroidDeck-Mod-Updater/tree/main/warhammer-survivors) (twin-stick controls, auto-aim) together with MelonLoader 0.7.3, directly on the phone.
- Copies the Proton launch option `WINEDLLOVERRIDES="version=n,b" %command%`, which the game needs to load MelonLoader. Set it in the game's Steam properties inside DroidDeck.
- 20 Minutes Till Dawn Revamped updates work exactly as in 0.2.0.
- Installs over Revamped Updater 0.2.0 (same package and signing key); one DroidDeck connection serves both games.

Install `DroidDeck-Mod-Updater-0.3.0.apk`. `SHA256SUMS.txt` lists its digest.
