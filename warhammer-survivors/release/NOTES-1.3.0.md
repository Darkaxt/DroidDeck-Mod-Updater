WHSurvivorsTweaks 1.3.0: twin-stick controls and auto-aim for Warhammer Survivors, with MelonLoader 0.7.3 included.

- **Windows:** copy everything in `WHSurvivorsTweaks-1.3.0.zip` next to `WarhammerSurvivors.exe`. Same file as on [Nexus Mods](https://www.nexusmods.com/warhammersurvivors/mods/6).
- **DroidDeck (Android):** install it with the [DroidDeck Mod Updater](https://github.com/Darkaxt/DroidDeck-Mod-Updater#warhammer-survivors-on-droiddeck) app, which reads `WHSurvivorsTweaks-1.3.0.json` to verify every file.
- **Steam Deck / Proton:** set the launch options to `WINEDLLOVERRIDES="version=n,b" %command%`.

The optional `Ultrawide` setting (off by default) ports the fix from Hush's [Ultrawide Support Patch](https://www.nexusmods.com/warhammersurvivors/mods/2); all credit for it goes to Hush. MelonLoader is by LavaGang (Apache-2.0).
